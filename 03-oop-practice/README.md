# OOP practice solutions

`oop_practice.py` implements every exercise visible in the linked Gist: complex-number addition/subtraction; age comparison for people; vector dot product; all circle comparisons; point comparisons by distance from the origin; matrix multiplication; `Vehicle`/`Car`/`Bicycle` overrides; `PersonRecord` with `Student` and `Employee`; and `BankAccount` with `SavingsAccount`, interest, balance checks, and transfers.

The source is dependency-free and includes a small runnable demonstration. Matrices use nested Python lists and validate dimensions. `Circle` and `Point2D` use `total_ordering` to provide the remaining comparison operators from equality and less-than.

```bash
python3 oop_practice.py
```
