# UML practice solutions

The linked Gist contains two scenarios. `diagrams.md` gives complete, text-renderable UML-style models: class diagrams, use-case diagrams, and the requested interaction sequences. Mermaid renders directly on GitHub. Multiplicities and the assumptions behind them are documented beside each model.

The hospital model uses separate payment strategies and explicit statuses. The ABCD model distinguishes member tiers, media types, payment types, and order lines. In both cases, clerks and organizer responsibilities are modeled as roles, while domain records carry the business state.
