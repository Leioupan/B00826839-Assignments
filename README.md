# Course assignment solutions

This repository contains five numbered assignment folders based on the linked course pages and Gists:

1. `01-bash-environment-setup/` — Bash setup script for Python, pip, and Jupyter.
2. `02-git-workflow/` — Git mini-exercise commands, answers, and reflection.
3. `03-oop-practice/` — Python operator-overloading and inheritance solutions.
4. `04-uml-practice/` — UML diagrams for the hospital and ABCD Records scenarios.
5. `05-design-patterns/` — creational, structural, and behavioral pattern examples (the three course links comprise one assignment).

Open a folder's README for its scope and run instructions. The source-based assignments include runnable examples; diagrams use Mermaid syntax supported by GitHub. No account names, repository URLs, or machine-specific credentials are embedded.
